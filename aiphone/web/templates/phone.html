Grandstream HT801 / HT802 setup guide

  1. Find the ATA's IP address: lift the handset and dial ***, then 02; it reads the address out. Open http://<ATA address> in a browser (default password admin, or the one on the sticker).
  2. For each port you use, open the FXS Port 1 (or FXS Port 2) tab and fill in:
