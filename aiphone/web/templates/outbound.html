Webhook

Any system that can open a URL (Home Assistant, a cron job, IFTTT, a doorbell…) can make the phone ring:

curl -X POST {{ base_url }}/api/webhook/{{ token }} \
  -H 'Content-Type: application/json' \
  -d '{"text": "Someone is at the front door.", "mode": "message"}'

Or simply open: {{ base_url }}/api/webhook/{{ token }}?text=Hello+there

textThe message, or what the conversation is about
modemessage (read out, default) or conversation
allow_replytrue to keep talking after the message
extensionWhich AI profile to use (its number), e.g. 1
lineline1 or line2
retriesHow often to try again if nobody answers

The token in the URL is the password; keep it private. API docs: /api/docs.
